## Ключевые проекты

### [pen-system-02](https://github.com/bylbozator/pen-system-02) — дипломный проект
Корпоративная система учёта и контроля поставок МТР (план/факт). Полноценный full-stack продукт:

- **Backend:** Python 3.11, FastAPI, SQLAlchemy 2.0, Celery + Redis, PostgreSQL 15
- **Frontend:** React 18, TypeScript 5, Vite, Tailwind CSS 3, Univer.js (онлайн-редактор таблиц с формулами)
- **Фичи:** импорт/экспорт Excel и PDF, ролевая модель с JSON-разрешениями, аудит действий, JWT, rate limiting
- **Инфраструктура:** Docker Compose, Nginx, Prometheus + Grafana

### [project-14-android-cicd](https://github.com/bylbozator/project-14-android-cicd) — DevOps
Сквозной CI/CD-пайплайн Android-приложения на GitHub Actions: сборка, lint, юнит-тесты с покрытием (JaCoCo), SonarQube-сканирование, публикация APK в JFrog Artifactory, уведомления в Teams, работа с AWS security groups.

### [project-03-linux-fundamentals](https://github.com/bylbozator/project-03-linux-fundamentals) — DevOps
Основы Linux для DevOps: пользователи и группы, права доступа, vi, поиск, EBS volume и монтирование ФС. Все 11 фаз выполнены, есть `setup-linux.sh` и `cleanup.sh`.
