## Обо мне

Окончила ПНИПУ по специальности «Информатика и вычислительная техника»
(профиль «Автоматизированные системы управления»), магистратура 09.04.01
в процессе. Разрабатываю онлайн-системы на Python от модели данных до
мониторинга, отношусь к качеству как к части разработки: пишу тесты,
настраиваю CI и держу проект документированным. В дипломном проекте с нуля
построила корпоративную систему учёта и контроля поставок для филиала ООО
«Газпром трансгаз Чайковский».

### [pen-system-02](https://github.com/bylbozator/pen-system-02) — дипломный проект
Корпоративная система план/факт учёта и контроля поставок МТР. Backend на
