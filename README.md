## Ключевые проекты

### [pen-system-02](https://github.com/bylbozator/pen-system-02) — дипломный проект
Корпоративная система учёта и контроля поставок МТР для филиала ООО
«Газпром трансгаз Чайковский». Полноценный full-stack продукт:
- **Backend:** Python 3.11, FastAPI, SQLAlchemy 2.0, Celery + Redis, PostgreSQL 15;
- **Frontend:** React 18, TypeScript, Vite, Univer.js (онлайн-таблицы с формулами);
- **Фичи:** импорт/экспорт Excel и PDF, ролевая модель с JSON-разрешениями,
  аудит действий, JWT, rate limiting, WebSocket;
- **Качество:** pytest (юнит/интеграционные), Playwright E2E, CI в GitHub Actions,
  Prometheus + Grafana.

[pen-system v1](https://github.com/bylbozator/pen-system) — первый запуск этой системы.

### [moon-courier-crisis](https://github.com/bylbozator/moon-courier-crisis) — игровой симулятор
Браузерная игра (чистый JS + Canvas) с сервер-авторитативной симуляцией на Node:
66 юнит-тестов и 29 тестов REST API, баланс калиброван автопрогоном бота.

### [wb-api-parser](https://github.com/bylbozator/wb-api-parser)
Laravel-приложение: выгрузка продаж, заказов, остатков и доходов из API
Wildberries-подобного сервиса в MySQL с SSL.

### [companies-data-case](https://github.com/bylbozator/companies-data-case)
Кейс обработки данных ~1200 компаний: ETL JSON→PostgreSQL, веб-страница на
Next.js, аудит 22 аномалий в данных, LLM-стек.

### [phishing-detector](https://github.com/bylbozator/phishing-detector)
Детектор фишинговых сайтов: проверка URL, разбор DOM через Selenium, оценка
локальной LLM и итоговый вердикт.
